# NEXUS CLIENT

An over-the-top **Minecraft cheat-client launcher UI** — 80+ modules, config profiles, inject theatrics, and a void/acid aesthetic.

> **Showcase only.** This does **not** inject into Minecraft, bypass anti-cheats, or modify a real game process. It’s a flashy launcher demo for fun / portfolio vibes.

## Run

```bash
cd nexus-client
npm install
npm run dev
```

## Features

- Boot sequence + particle grid background
- Categories: Combat, Movement, Player, Render, World, Misc, Exploit, HUD
- 80+ modules with per-module settings (sliders, modes, toggles)
- Profiles: RAGE / LEGIT / HVH / GHOST / GOD
- Search, panic clear (Esc), inject & launch overlay
- Responsive layout
