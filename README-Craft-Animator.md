# Craft Animator

Open-source Adobe Animate–style editor lives in [`craft-animator/`](./craft-animator/).

### Desktop (double-click)

```bash
cd craft-animator
npm install
npm run dist:linux       # or dist:win on Windows
npm run desktop:install  # copies AppImage / shortcut to Desktop
```

### Browser

```bash
cd craft-animator && npm install && npm run dev
```

Import DeviantArt / Animate `.fla` or zipped XFL puppets, or start from the Maple demo rig.
